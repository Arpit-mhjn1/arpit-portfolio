# Arpit Mahajan — Interactive 3D Developer Portfolio 🚀

An ultra-modern, interactive, and visually immersive personal developer portfolio built for **Arpit Mahajan** (*Aspiring Software Engineer | Java & Spring Boot Developer | AI & Machine Learning Enthusiast*). 

Featuring real-time celestial simulations, a 24-key interactive 3D isometric musical keyboard, custom liquid cursor physics, and sleek glassmorphic UI.

---

## 🌟 Key Features & Highlights

### 🌌 1. Live Solar System Orrery & Cosmic Background
- **Real-Time HTML5 Canvas Engine:** Renders a continuous, high-performance cosmic background behind the entire application.
- **The Sun & Concentric Orbits:** Anchored at the upper-right focal point with a dynamically pulsing solar corona and subtle elliptical orbital rings.
- **All 8 Orbiting Solar System Planets:**
  - **Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, & Neptune** travel along their orbits at realistic relative orbital speeds.
  - **Earth's Moon:** Features a miniature silver Moon actively orbiting around Earth!
  - **Saturn System:** Rendered with wide, tilted 3D planetary rings correctly overlapping the gas giant sphere.
- **Dynamic Starfield:** Dense starry background with twinkling alpha transitions and responsive resizing.

---

### 🎹 2. Interactive 24-Key 3D Isometric Cyber Keyboard (Skills Deck)
- **True 3D Isometric Perspective:** 4 rows of 6 keys (`1-6`, `Q-Y`, `A-H`, `Z-N`) projected in 3D space (`rotateX(60deg) rotateZ(-45deg)`).
- **Vibrant Rainbow Neon Palette:** Every single one of the 24 keys features a distinct, highly saturated popping color (Electric Cyan, Neon Rose, Kelly Green, Royal Azure, Golden Marigold, Hot Pink, etc.).
- **Official Technology Logos:** Integrated using **Devicon**, **SimpleIcons**, custom **Inline SVGs**, and **Lucide Icons**:
  - **Row 1 (`1-6`):** Docker, Postman, React.js, MongoDB, Linux, Apache Pig.
  - **Row 2 (`Q-Y`):** C++, Python, Java, PHP, JavaScript, HTML5.
  - **Row 3 (`A-H`):** CSS3, Spring Boot, PostgreSQL, Pandas, NumPy, Power BI.
  - **Row 4 (`Z-N`):** Scikit-learn, Git/GitHub, Object-Oriented Programming (OOPs), Software Development, AI & Machine Learning, AWS (Amazon Web Services).
- **24-Note Melodic Web Audio Synthesizer:** Pressing or clicking keys triggers warm, melodic musical notes spanning a 24-note scale (from Middle C4 `261.63 Hz` up to sparkling crystal chimes `2637.02 Hz`).
- **3D Drag & Rotate Control:** Click and drag (or swipe on touch devices) to rotate and tilt the entire 3D keyboard deck in real time.
- **Dynamic Skill Display HUD:** Hovering or pressing any key announces the skill name on a glowing gradient display board above the keyboard.

---

### 🛸 3. Custom Liquid Jellyfish Cursor Physics
- **Sleek Custom Floating Ring:** Features a crisp `56px` circular outline with a high-contrast `6px` center dot.
- **Fluid Spring Physics:** Tracks mouse velocity and stretches dynamically during rapid movement.
- **Interactive Hover Adaptation:** Smoothly scales up by 40% and glows brighter when hovering over buttons, cards, and 3D keys.

---

### 🌓 4. Dual Theme Support (Dark & Light Modes)
- **Glassmorphism Design System:** Clean frosted-glass navigation bar, cards, and buttons.
- **Instant Theme Switcher:** Seamless one-click toggle between sleek deep-space Dark Mode and crisp Light Mode.

## 🛠️ Technology Stack & Architecture

- **Core Structure:** Semantic HTML5
- **Styling & Design System:** Vanilla CSS3 (Custom CSS Tokens, Variables, Isometric 3D Transforms, Glassmorphism)
- **Logic & Animation Engine:** Modern ES6+ JavaScript, **GSAP (GreenSock Animation Platform)**
- **Audio & Visual Engines:** **Web Audio API** (Custom Synthesizer), **HTML5 Canvas 2D API** (Solar System Orrery)
- **Iconography:** Devicon CDN, SimpleIcons SVGs, Lucide Icons

## 📦 Getting Started / Running Locally

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/Arpit-mhjn1/portfolio-project.git
   cd portfolio-project
   ```
2. **Open `index.html`:**
   Simply double-click `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari) or use a local development server such as VS Code Live Server:
   ```bash
   npx serve .
   ```
